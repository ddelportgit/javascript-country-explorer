# Country Explorer

A country explorer application built with HTML, CSS, and JavaScript. It retrieves country information from an external API and allows users to search, filter, and save favourite countries.

## Features

- Fetches country data from the countries.dev API.
- Displays country flags, names, capitals, regions, and populations.
- Search countries by name.
- Filter countries by region.
- Add countries to favourites.
- View favourite countries separately.
- Save favourites using localStorage.
- Loading and error states.
- Responsive layout.

## Technologies

- HTML5
- CSS3
- JavaScript
- REST API
- Fetch API
- localStorage

## What I Learned

- Fetching and displaying data from an external API.
- Working with asynchronous JavaScript using async/await.
- Handling API errors with try/catch.
- Filtering arrays using filter().
- Dynamically creating HTML elements with JavaScript.
- Managing application state.
- Saving and retrieving data with localStorage.
- Combining search and multiple filters.
